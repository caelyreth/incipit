### 1.0.0-alpha.1

Incipit 的首個公開 Alpha 版本 —— 一個以 Go 建構的寧靜、本地優先寫作空間。

#### 寫作與編輯器

- 輸入時即時呈現標題、清單、待辦、引用、程式碼區塊、表格與附圖說圖片的 Markdown 排版。
- 支援 TeX 與 Typst 行內公式及公式區塊。
- 智慧標點與中日韓排版，包含標點擠壓與寬度調整、中西文混排間距、括號引號成對補全及打字機模式。
- 依結構層級選取範圍、兩步驟防誤刪保護、文稿內尋找、即時字詞統計，以及 macOS 拼字、文法與行內預測輸入。

#### 文庫、搜尋與工作區

- 原野與清單兩種文庫檢視，支援巢狀群組、顏色標籤、標籤、釘選、托盤暫存與書桌並排分割編輯。
- 全文搜尋與快速切換面板，支援篩選鍵（$tag、$in、$updated、$words、$has、$task）與已儲存搜尋書籤。
- 基於本地 SQLite 的筆記本目錄，內建自動驗證備份、當機安全文稿復原與可自訂快捷鍵。

#### 外觀、語言與匯出

- 星野（深色）、破曉（淺色）與跟隨系統主題，可調介面與正文字號，並可選拉丁、中文與日文 Noto 字型。
- 介面完整支援英文、日文、簡體中文與繁體中文。
- 支援將群組與文稿匯出為 Markdown（可選 YAML Front Matter）與分頁 PDF。
- 涵蓋 macOS（Apple Silicon 與 Intel）、Linux 與 Windows 的簽章自動更新與差異補丁。

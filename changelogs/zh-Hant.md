### 1.0.0-alpha.4

一次針對搜尋輸入的快速修正。

- **輸入搜尋時更平穩：** 原野不再隨每次按鍵反覆重排，而是等輸入稍作停頓後再一次更新。

### 1.0.0-alpha.3

一次小幅的後續更新：讓書桌動畫重新流暢，並順手修飾了幾處細節。

- **書桌動畫更流暢：** 在原野與書桌之間切換時，動畫再次恢復順暢。alpha.2 中，書桌的圓角會在動畫的每一格都以較耗效能的方式重新繪製，可能造成卡頓。
- **更新說明支援格式：** 「設定 › 更新」中的更新說明不再顯示原始 Markdown，粗體、斜體、行內程式碼與編號清單都會正確呈現。
- **設定中的檢視切換更清楚：** 設定裡沒有可以列出的內容，因此原野／清單切換按鈕在這裡會變暗；垃圾桶現在也能從選單切換為清單檢視。

### 1.0.0-alpha.2

這是一次細節打磨的更新：主題切換更加流暢、書桌更整齊，Windows 與 Linux 上的視窗按鈕也不再被擋住。

- **深淺主題無縫切換：** 在「星野」與「破曉」之間切換時，整個視窗會一起漸變。書桌的工具列、文稿標題列與原野中的書桌側欄，不會再慢半拍、等主題換完才開始變色；控制項的深淺也改在過渡到一半時才翻轉，不再一開始就突然跳換。
- **書桌外觀更一致：** 書桌的圓角改為與托盤、「已收藏」相同，並加上一道細框線。在原野與全螢幕之間飛入飛出時，框線會提早淡出，圓角也會逐步收成直角，貼齊視窗邊緣時不再露出縫隙。托盤空著時的提示文字也已置中。
- **搜尋建議不再消失：** 搜尋列停在視窗底部時，「按鍵」等建議會移到有空間的一側顯示，不會被藏起來。
- **支援 Windows 與 Linux 的視窗按鈕：** 「關閉」按鈕不再與系統的視窗控制按鈕重疊；替 macOS 紅綠燈按鈕預留的左側空白，現在只會出現在 macOS 上。
- **更新更可靠：** 無法連上主要更新伺服器時，會改從 GitHub Releases 下載更新。

### 1.0.0-alpha.1

Incipit 的第一個公開 Alpha 版本來了——這是一座以 Go 打造、安靜且資料全數留在本機的寫作空間。

#### 寫作與編輯器

- **即時 Markdown 排版：** 輸入標題、清單、待辦事項、引言、表格與附圖說的圖片時即刻呈現版面，格式記號也可依習慣選擇保留顯示或隱去。
- **數學公式：** 行內公式與獨立公式區塊皆同時支援 TeX 與 Typst 語法。
- **程式碼區塊：** 程式碼會落在獨立的視覺面板上，依語言標記自動上色，換行時自動延續縮排，在結尾圍欄按 Enter 也能順暢切回正文。
- **西文與中日韓排印細節：** 鍵入 `--` 與 `...` 自動轉換為破折號和刪節號，搭配智慧引號與成對括號補全、全形標點調整、中英文混排間距與微光修改提示；開啟打字機模式後，正在書寫的那一行會始終停在畫面中央附近。
- **流暢的編輯與導覽：** 選取文字後會浮現格式工具列；透過快捷鍵即可上下搬移區塊或切換清單、待辦；Tab 縮排與表格新增列皆有提示引導；並提供依語法層級逐步擴大的選取、連點三下選整句、兩步驟防誤刪保護、文稿內尋找，以及即時字詞與漢字統計。
- **更懂排版的剪貼簿：** 貼上網頁內容時自動轉為乾淨的 Markdown，也提供「貼上並符合樣式」；複製為純文字時會保留 Markdown 語法。
- **macOS 原生寫作輔助：** 整合系統級拼字與文法檢查（自動修正後點擊底線即可還原）、按 Tab 採納的行內預測文字，以及用力長按或右鍵查詢詞彙。

#### 文庫、搜尋與工作區

- **原野、清單、托盤與書桌：** 在自由展開的「原野」與條理分明的「清單」檢視間自由切換；支援多層群組、色票標記、標籤、釘選與卡片縮圖預覽。「托盤」用來暫放手邊文稿；「書桌」可並排分欄編輯，每一欄都會記住各自的捲動位置。
- **全文搜尋與指令面板：** 搜尋與「前往文稿」支援 `$tag`、`$in`、`$updated`、`$words`、`$has`、`$task` 等篩選條件，可將常用查詢存成書籤，也能隨時開啟指令面板執行操作。
- **本機儲存安心防護與按鍵設定：** 所有內容都保存在本機 SQLite 筆記本資料夾內，內建垃圾桶、自動驗證備份、當機復原、啟動時清理未引用圖片與單一視窗喚起；自訂快速鍵時直接按下組合鍵，就能依 `$key` 篩選與調整。

#### 初次設定、外觀與匯出

- **引導式初次體驗：** 首次開啟即可挑選筆記本存放資料夾（Linux 支援 XDG 資料目錄），並直接在範例上試調書寫手感和版面風格。
- **主題、字型與動態效果：** 提供「星野」（深色）、「破曉」（淺色）與跟隨系統三種主題，強調色會呼應所屬群組的色彩，動畫亦尊重系統的「減少動態效果」設定。內文可切換襯線體與無襯線體，內建含即時字樣預覽的可搜尋字型選擇器、中文字形變體偏好與按需下載的 Noto 字型。
- **多語系與匯出：** 介面完整提供英文、日文、簡體中文與繁體中文；支援將單篇文稿或整個群組匯出為 Markdown（可選附帶 YAML Front Matter）與分頁排版的 PDF。
- **跨平台簽章自動更新：** 支援 macOS（Apple Silicon 與 Intel）、Windows（`amd64` 與 `arm64`）及 Linux（`.tar.gz`、`.deb`、`.rpm` 與 `install.sh`），具備 `release` / `prerelease` 雙通道簽章驗證與輕量差異更新補丁。

### 1.0.0-alpha.4

検索の入力まわりを直した小さな修正です。

- **入力中の検索が落ち着きました:** 検索欄に文字を打つたびにフィールドが並び替わることはなくなり、入力が少し止まってから一度だけ更新されます。

### 1.0.0-alpha.3

デスクの動きをなめらかにし、細かな粗を整えた小さなアップデートです。

- **デスクのアニメーションがなめらかに:** フィールドとデスクの行き来が、再びなめらかに動くようになりました。alpha.2 では、デスクの角丸をアニメーションの毎フレームで描き直す処理が重く、カクつくことがありました。
- **リリースノートを整形して表示:** 「設定 › アップデート」のリリースノートが Markdown のままではなく、太字・斜体・インラインコード・番号付きリストとして表示されるようになりました。
- **設定画面での表示切り替えを分かりやすく:** 設定画面には一覧にする項目がないため、フィールド／リストの切り替えボタンを淡色表示にしました。また、ゴミ箱もメニューからリスト表示に切り替えられるようになりました。

### 1.0.0-alpha.2

細部を磨き込んだアップデートです。テーマの切り替えがよりなめらかになり、デスクの見た目が整いました。Windows と Linux ではウインドウ操作ボタンとの重なりも解消しています。

- **ライト／ダークの切り替えがひと続きに:** スターフィールドとデイブレイクを切り替えると、ウインドウ全体がひとつの流れで移り変わるようになりました。デスクのツールバーやシートの見出し、フィールドのデスクレーンが遅れて色を追いかけることはもうありません。コントロールの明暗も、切り替えの始まりで急に反転するのではなく、ちょうど中ほどで切り替わります。
- **デスクの見た目をそろえました:** デスクの角丸をトレイや「保存済み」と同じにし、細い枠線を加えました。フィールドとの間を行き来するアニメーションでは、枠線を早めに消し、角も少しずつ直角に近づけるので、ウインドウの縁との間に継ぎ目が見えません。トレイが空のときの案内文も中央に置きました。
- **検索の候補が隠れなくなりました:** 検索欄がウインドウの下端にあるときでも、「キー」などの候補が消えずに、空いている側へ回り込んで表示されます。
- **Windows・Linux のウインドウ操作に対応:** 「閉じる」ボタンがシステムのウインドウ操作ボタンと重ならなくなりました。macOS の信号ボタン用の左側の余白も、macOS でだけ確保されます。
- **アップデートの信頼性を向上:** メインのアップデートサーバーにつながらないときは、GitHub Releases からダウンロードするようになりました。

### 1.0.0-alpha.1

Go でつくった、静かでローカルファーストな執筆ワークスペース「Incipit」の最初のパブリックアルファ版です。

#### 書くこと・エディタ

- **リアルタイムの Markdown 整形:** 見出し、リスト、タスク、引用、表、キャプション付き画像を入力と同時に整えます。書式記号を見せるか隠すかも好みに合わせて選べます。
- **数式:** TeX と Typst の両方に対応し、インライン数式も数式ブロックもそのまま書けます。
- **コードブロック:** 独立したパネル上に表示され、言語名に応じたシンタックスハイライトや改行時のインデント引き継ぎ、閉じフェンスまわりの改行に対応しました。
- **タイポグラフィと和欧混植:** `--` や `...` の自動変換、スマートクォートや括弧のペア入力、句読点の全角調整、和欧文間のスペース挿入、変更箇所を知らせる控えめなパルス表示、書いている行を常に視線の高さに保つタイプライターモードを備えています。
- **気持ちのよい編集と移動:** 選択範囲に浮かぶ書式ツールバー、キーボードでのブロック上下移動やリスト変換、階層・表の行追加ガイド、構造単位での段階的な範囲選択、トリプルクリックでの文選択、2段階の誤削除防止、シート内検索、リアルタイムの語数・文字数・CJK 文字数カウントが使えます。
- **賢いコピー＆ペースト:** Web などから貼り付けた HTML をきれいな Markdown に変換するほか、書式を合わせてペーストしたり、プレーンテキストとして Markdown 記法ごとコピーしたりできます。
- **macOS の文章支援:** スペル・文法チェック（クリックで修正前の語へ戻せる自動修正付き）、Tab で確定できるインライン予測入力、感圧タッチやコンテキストメニューからの「調べる」に対応しました。

#### ライブラリ・検索・ワークスペース

- **フィールド・リスト・トレイ・デスク:** 空間的に見渡せる「フィールド」と一覧性の高い「リスト」を切り替えられます。階層グループ、カラー見本、タグ、ピン留め、カード上の画像プレビュー、一時置きに便利な「トレイ」、スクロール位置を保ったまま並べて書ける「デスク」の分割カラムを用意しました。
- **検索とコマンド:** 全文検索や「シートへ移動」から `$tag`・`$in`・`$updated`・`$words`・`$has`・`$task` などのフィルタで素早く絞り込めます。よく使う検索条件のブックマークやコマンドパレットも利用できます。
- **ローカル保存の安心設計とキー設定:** ノートブックは手元の SQLite フォルダに保存され、ゴミ箱、自動検証付きバックアップ、クラッシュからの安全な復元、起動時の不要画像の整理、二重起動時の既存ウィンドウフォーカスに対応しています。ショートカットはキーをそのまま押して `$key` で検索・変更できます。

#### はじめ方・外観・書き出しとアップデート

- **初回セットアップ:** ノートブックの保存先（Linux では XDG データフォルダにも対応）や書き心地・見た目を試しながら最初の設定を終えられます。
- **テーマと文字組み:** 夜に寄り添う「スターフィールド」、紙面のような「デイブレイク」、システム連動の3つのテーマに加え、開いているグループのアクセント色や「視差効果を減らす」に沿ったアニメーションを採用しました。セリフ（明朝）・サンセリフ（ゴシック）の本文切り替え、見本を確かめながら探せるフォント選択、文章中の漢字の字体切り替え、必要に応じた Noto フォントのオンデマンド取得にも対応しています。
- **多言語と書き出し:** 英語・日本語・簡体字中国語・繁体字中国語に対応し、シートやグループを Markdown（YAML フロントマター付きも可）やページ分割された PDF として書き出せます。
- **クロスプラットフォームの署名付き自動更新:** macOS（Apple Silicon / Intel）、Windows（`amd64` / `arm64`）、Linux（`.tar.gz`・`.deb`・`.rpm`・`install.sh`）向けに配布し、`release` / `prerelease` の両チャンネルで署名と差分パッチによる安全なアップデートを届けます。

### 1.0.0-alpha.1

Incipit 的首个公开 Alpha 版本与你见面了。它以 Go 编写，是一处安静、数据留在本地的写作空间。

#### 写作与编辑器

- **边写边排的 Markdown：** 输入标题、列表、待办、引用、表格和带图注的图片时即时呈现效果，标点与格式符号也可自由选择显示或收起。
- **公式写作：** 行内公式与公式块同时兼容 TeX 和 Typst 语法。
- **代码块面板：** 代码块拥有独立的视觉面板，可根据语言标识着色高亮，回车自动沿用当前行缩进，末尾围栏处换行顺滑衔接正文。
- **西文与中文排版细节：** 输入 `--`、`...` 时自动替换为破折号与省略号，支持智能引号与成对括号补全、全角标点与中西文混排间距；每次自动排版都会以微光提示改动位置，开启打字机模式还能让当前输入行稳稳停在视野中央。
- **顺手的编辑与导航：** 选中文字即现浮动格式条；用键盘就能上下挪动段落、切换列表与待办；Tab 缩进与表格加行一目了然；支持按语法结构逐级扩大选区、三击整句选中、两步防误删保护、文内即时查找以及字词与中文字符统计。
- **聪明的剪贴板：** 粘贴网页内容时自动转为干净的 Markdown，也可“粘贴并匹配样式”；复制纯文本时会保留 Markdown 标记。
- **macOS 原生辅助：** 接入系统级拼写与语法检查，自动纠错后点一下即可恢复原词，支持行内幽灵字预测（按 Tab 采纳）以及重按或右键查词。

#### 文库、搜索与工作区

- **原野、列表、托盘与书桌：** 可在自由排布的“原野”和条理清晰的“列表”视图间切换；支持多级分组、颜色标记、标签、置顶和文稿配图缩略图。想暂时手边留几篇参考，可以放到“托盘”；需要在“书桌”分栏对照写作时，每一栏都会记住自己的滚动位置。
- **全文检索与命令面板：** 搜索与“前往文稿”支持 `$tag`、`$in`、`$updated`、`$words`、`$has`、`$task` 等筛选条件，常用检索可存为书签，常用操作也能从命令面板一键直达。
- **本地存储与快捷键：** 整本笔记存放在本地 SQLite 文件夹中，配有废纸篓、自动校验备份、崩溃恢复、启动时清理闲置图片与单实例唤醒；快捷键设置里直接按下组合键即可按 `$key` 筛选或改绑。

#### 初次上手、外观与导出

- **引导式开箱设置：** 初次打开即可自选笔记本存放位置（Linux 下支持 XDG 数据目录），并在样例中试调书写手感和界面观感。
- **主题、字体与动效：** 内置“星野”（深色）、“破晓”（浅色）与跟随系统三种主题，强调色会随当前分组柔和变化，并遵循系统的“减弱动态效果”设置。正文可切换衬线与无衬线风格，内置带实时字样预览的可搜索字体选择器，支持混排汉字字形切换与按需下载 Noto 字体。
- **多语言与导出：** 界面原生提供英文、日文、简体中文与繁体中文；分组与文稿均可导出为 Markdown（支持附带 YAML Front Matter）或分页排版的 PDF。
- **跨平台签名自动更新：** 覆盖 macOS（Apple Silicon 与 Intel）、Windows（`amd64` 与 `arm64`）以及 Linux（`.tar.gz`、`.deb`、`.rpm` 与 `install.sh`），支持 `release` / `prerelease` 双通道签名更新与体积小巧的增量补丁。

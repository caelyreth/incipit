### 1.0.0-alpha.1

Incipit 的首个公开 Alpha 版本 —— 一个基于 Go 构建的宁静、本地优先的写作空间。

#### 写作与编辑器

- 键入时实时呈现标题、列表、待办、引用、代码块、表格与带图注图片的 Markdown 排版。
- 支持 TeX 与 Typst 行内公式和公式块。
- 智能标点与中日韩排版，包含标点挤压与宽度调整、中西文混排间距、括号引号成对补全及打字机模式。
- 按语法结构层级选区、两步防误删保护、文稿内查找、实时字词计数，以及 macOS 拼写、语法与行内预测输入。

#### 文库、搜索与工作区

- 原野与列表两种文库视图，支持嵌套分组、颜色标签、标签、置顶、托盘暂存以及书桌分栏并排编辑。
- 全文搜索与快速切换面板，支持筛选键（$tag、$in、$updated、$words、$has、$task）和已保存搜索书签。
- 基于本地 SQLite 的笔记本目录，内置自动校验备份、崩溃安全文稿恢复与可自定义快捷键。

#### 外观、语言与导出

- 星野（深色）、破晓（浅色）与跟随系统主题，可调界面与正文字号，并可选拉丁、中文与日文 Noto 字体。
- 界面完整支持英文、日文、简体中文与繁体中文。
- 支持将分组与文稿导出为 Markdown（可选 YAML Front Matter）及分页 PDF。
- 覆盖 macOS（Apple Silicon 与 Intel）、Linux 与 Windows 的签名自动更新与增量补丁。

# Bundled Fonts

No font is stored in Git. Fetch them with:

```sh
go tool fetch
```

The same command is wired as `go generate ./internal/ui/theme`. It downloads each
font to its ignored path here, verifies its checksum, and installs it
atomically.

## Prose

Prose defaults to the host platform's generic `serif` or `sans-serif` family
(with optional selection of any installed system font). The Typeface settings
also offer downloadable Noto Serif and Noto Sans builds (including upright and
italic weights for Latin, plus SC, TC, HK, and JP glyph forms for Chinese and
Japanese), fetched on demand from `fonts.gstatic.com` (with `fonts.gstatic.cn`
as fallback), verified against the SHA-256 hashes pinned in
`internal/app/fonts/catalog.go`, and kept locally on the machine. The catalog
is generated by `go tool fonts`, and the Noto faces are licensed under the SIL
Open Font License 1.1 in `OFL.txt`.

## Math

`NewCMMath-Book.otf` is New Computer Modern Math, Book weight, as pinned by
Typst's assets and by the untie renderer's own test fixtures:

```text
https://github.com/typst/typst-assets/blob/94dcb990edb36311ef85162baa26e4a8205e0bf0/files/fonts/NewCMMath-Book.otf
SHA-256 2ea09ebc9167b1e1a66f31390dc917f2d4004ecfca72d51b28010e4ad6becd95
```

Formulas are laid out from its OpenType MATH table by untie, which reads the
font's bytes directly; it is not registered with the platform. New Computer
Modern is licensed under the GUST Font License
(https://www.gust.org.pl/projects/e-foundry/licenses).
